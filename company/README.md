# 🏢 (주)부동산공화국 게임즈 — 가상 게임회사 운영 매뉴얼

aptgame.kr 게임들을 매일 자동으로 **검증 → 수정 → 운영 점검 → 홍보 준비 → 신규 기획 → 사장님 보고**하는 회사입니다.
각 부서는 정해진 시간에 Claude가 새로 출근(예약 작업)해서, 이 폴더의 지침을 읽고 일한 뒤 보고서를 남깁니다.

- **대표(CEO)**: 사장님. 결재만 합니다.
- **상황판**: https://aptgame.kr/hq/ (부서 보고가 push될 때마다 자동 갱신)
- **사업 품목**: 나의 첫 서울아파트(웹·앱인토스·MS 스토어), 재건축 조합장 키우기(웹·앱인토스), 부동산 공화국(보류)

## 일이 흐르는 순서

```
QA검증팀 ──버그 접수──▶ 개발팀 ──수정·QA통과──▶ 자동 배포(Render)
   ▲                         ▲
   │                         └── 승인된 기획안(사장님 결재) ◀── 기획팀
라이브운영팀(통계·신고) ──이상 발견──▶ 버그 접수
마케팅팀 ──스레드 초안──▶ 상황판 게시 대기열(사장님이 버튼 한 번)
수익화팀 ──광고·제휴 안건──▶ 작은 건 자동승인 → 개발팀
모든 부서 보고 ──▶ 경영지원실 ──아침 브리핑──▶ 사장님 📱
```

## 사장님이 하는 일 (이것만)

1. 아침 브리핑 알림 확인
2. 결재함(`board/결재함.md`)의 안건에 대해 아무 Claude 대화에서 **"P-003 승인"**, **"M-002 반려"** 처럼 말하기
3. 앱인토스·스토어 심사 제출, 본인인증, 결제처럼 대표 본인만 할 수 있는 일

## 폴더

- `RULES.md` — 전 부서 공통 사규 (절대 하면 안 되는 일)
- `departments/` — 부서별 업무 지침 (예약 작업이 매번 여기를 읽음 → 지침을 고치면 다음 출근부터 반영)
- `board/bugs/` — 버그 접수증 (BUG-날짜-번호.md)
- `board/proposals/` — 기획안 (P-번호.md)
- `board/marketing/` — 홍보 초안 (M-번호.md)
- `board/결재함.md` — 사장님 결재 대기 목록
- `reports/YYYY-MM-DD/` — 부서별 일일 보고서
- QA 도구: `tools/qa/run.sh` (게이트), `tools/qa/seoul_sim.js` (봇), `tools/qa/smoke.py` (페이지 점검)
