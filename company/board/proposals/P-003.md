- 나오는 조건(w): `owns('ipj').some(p => p.conv && p.stage >= 4 && !p.rcFee) && yearOf() >= 2018 ? 2 : 0`

  - fee = `r2(propValue(p) * .06)`, 1주택이고 `S.t - p.buyT >= 20`(10년 이상 보유)이면 절반(감면 반영)
- 선택지:
  1. `준공 때 내기로 하고 분담금에 더한다` (s: '분담금 증가 · 확실') → `p.dues = r2(p.dues + fee); p.rcFee = true;` 결과 `분담금이 ${won(p.dues)}이 됐습니다. 계획에 넣어 두면 입주 때 당황하지 않습니다.`
  2. `조합과 함께 감액 소송에 참여한다` (s: '절반 확률로 감액 · 사업 지연') → 50%: `p.dues = r2(p.dues + fee * .5)`, 결과 `소송 끝에 부담금이 절반으로 줄었습니다. 대신 사업이 한동안 멈췄습니다.` / 50%: `p.dues = r2(p.dues + fee)`, 결과 `소송에서 졌습니다. 부담금은 그대로입니다.` — 두 경우 모두 `p.slow = true; p.wait = (p.wait || 0) + 2; p.rcFee = true;`
  3. (S.age >= 60일 때만 ok) `고령자 납부유예를 신청한다` → `p.rcFee = true; S.rcDefer = r2((S.rcDefer||0) + fee);` 결과 `팔거나 상속할 때까지 미뤘습니다.` — 개발팀 판단으로 구현이 번거로우면 3번은 빼도 됨(게임 나이 49세가 상한이라 거의 안 나옴 → **빼는 쪽 권장**)
