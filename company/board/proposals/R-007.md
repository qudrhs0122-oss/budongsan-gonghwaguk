# R-007 서울아파트 반기 결과 화면: 쿠팡 배너를 '다음 반기로' 버튼에서 떼기
상태: 자동승인
게임: 서울아파트(첫 아파트) / 종류: 광고 배치 조정(정책 위험 줄이기)
부서: 💰 수익화팀 / 올린 날짜: 2026-11-24

왜:
- 코드 점검(11/24): `src/seoul/ui.js` 반기 결과 화면에서 쿠팡 배너(`data-sub="seoulres"`)가 **'다음 반기로 »' 버튼 바로 아래 28px**에 붙어 있음.
- 이 버튼은 한 판에 약 40번 누르는 '주 조작 버튼'이다. 휴대폰에서 손가락이 조금만 미끄러져도 배너가 눌릴 수 있음 → 지침의 "버튼 바로 옆·실수 클릭을 노린 배치 금지", "게임 조작 중 화면·버튼 바로 옆에는 넣지 말 것"에 **걸릴 소지**.
- 실수 클릭은 쿠팡 파트너스에서도 부정 클릭으로 볼 수 있고, 무엇보다 사이트 전체 신뢰를 깎음. 지금은 레드라인 '위반 확정'은 아니지만 안전하게 미리 고친다.

무엇을 (개발팀):
1. `seoulres` 배너 위 여백을 28px → **최소 72px**로 늘리고, 배너 위에 얇은 구분선(1px, 연한 회색)을 둔다. 배너는 지금처럼 화면 맨 아래 유지(버튼 위로 올리지 않음).
2. 배너가 늦게 뜨면서 버튼 위치가 밀리지 않는지 확인 (배너가 버튼 **아래**라 밀림 없음 — 유지).
3. 엔딩 화면 `seoulend`도 같은 기준: '다른 게임' 링크와 32px → 72px + 구분선.
4. 360px 폭 휴대폰 화면에서 버튼 하단과 배너 상단 사이가 손가락 한 마디(약 70px) 이상인지 QA 스크린샷 1장.

예상 효과: 수익 변화 거의 없음(정상 클릭은 그대로, 실수 클릭만 줄어듦). 계정 제재 위험 감소가 목적.

정책 위험: 없음 (오히려 줄어듦. 광고 개수·빈도 변화 없음, 문구 변화 없음, 대가성 문구 유지).

크기: 소(스타일 2줄 + 스크린샷)
