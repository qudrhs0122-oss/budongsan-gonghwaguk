# R-004 다른 플랫폼 입점 조사·준비: 삼성 Instant Plays(갤럭시 H5 게임) / 원스토어
상태: 결재대기
게임: 서울아파트·부루마블 / 종류: 새 기능(유통 확대)
부서: 💰 수익화팀 / 올린 날짜: 2026-11-20

왜:
- 우리 게임은 둘 다 **HTML5 웹게임**이라 앱을 새로 만들지 않고도 H5 게임을 받는 곳에 올릴 수 있음.
- 삼성 Instant Plays는 갤럭시 폰에서 설치 없이 바로 하는 H5 게임 유통 채널(공식 개발자 문서 있음). 국내 갤럭시 점유율이 높아 노출 효과가 큼.
- 원스토어는 2026년 중소 개발사 수수료 50% 감면을 상시 운영 중이고, 원플레이·원웹샵 등 웹 기반 유통을 넓히는 중(기사 기준).
- 판수가 늘면 광고 노출이 같이 늘어나는 구조라, 광고 승인만 기다리는 지금 가장 '레버리지 큰' 일.

무엇을 (1단계 = 조사·준비만, 등록 제출은 사장님):
1. 수익화팀: 각 플랫폼의 H5 게임 요건(용량·광고 SDK 허용 여부·외부 링크 정책·심의/등급 필요 여부)을 공식 문서로 표로 정리 → 다음 출근 보고서.
2. 개발팀(승인 후): 플랫폼별 번들이 필요하면 `toss-seoul` 처럼 별도 폴더로 만들되, 외부 결제·후원 링크는 빼고, 광고는 그 플랫폼이 허용하는 방식만.
3. 사장님: 개발자 계정 등록·본인인증·심사 제출(사규상 Claude가 못 함).

예상 효과(보수적): 입점 후 하루 신규 20~50판 가정 → 판당 전면 2~3회 노출. 광고 단가가 확정되지 않아 금액 추정은 광고 승인 후. 1~2주 걸림.

정책 위험: 있음(관리 가능)
- 게임 등급분류: 국내 스토어 게임 출시는 등급분류(자체등급분류 포함)가 필요할 수 있음 → **신고는 사장님만**. 확인 후 결재함에 별도 표기.
- 플랫폼마다 광고 SDK·외부 링크 정책 다름 → 레드라인 + 플랫폼 정책 둘 다 지킴.
- 미성년 이용자 노출 가능 → 도박성 문구 없는지 재점검(현재 없음).

사장님이 할 일: 승인되면 `사장님할일.md` 에 개발자 등록 줄을 추가(지금은 추가 안 함 — 조사 결과 보고 결정).

크기: 중(조사 반나절 + 번들 1~2일)
