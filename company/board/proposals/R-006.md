# R-006 후원하기를 '카카오페이 송금 링크(+토스)'로 — 후원 플랫폼 가입 없이
상태: 자동승인   (R-003 승인 범위 안에서 '받는 방법'만 바꿈 · 사장님 지시 11/21 "카카오페이나 쉬운송금으로")
게임: 사이트 공통(aptgame.kr 웹) / 종류: 새 기능(후원)
부서: 💰 수익화팀 / 올린 날짜: 2026-11-24 / 관련: R-003(승인), 지시사항 (revenue) 11/21

왜:
- R-003에서 투네이션 같은 후원 플랫폼 가입을 사장님할일로 올렸지만 3일째 진행이 없음(가입·본인인증·정산계좌 3단계라 귀찮음).
- 사장님 지시: 카카오페이·토스 같은 '이미 쓰는 송금'으로 받기. → **새 가입 0건, 링크 1개만 주시면 끝.**

방법 비교 (조사 11/24)
| 방법 | 사장님 할 일 | 계좌번호 노출 | 판단 |
|---|---|---|---|
| ① **카카오페이 송금코드(QR·링크)** | 카카오페이에서 내 송금코드 열기 → 링크 복사 1번 | 안 됨 (QR/링크만) | **1순위.** 카카오가 출시 때 "결제·정산·기부 등 비지인 송금"용이라고 소개. 친구 추가 없이 QR만으로 송금 |
| ② 토스 아이디 링크(toss.me/아이디) | 토스 앱에서 토스 아이디 만들기 → 링크 복사 | 안 됨 | **보조.** 2022년 베타 서비스라 지금도 열리는지 불확실(종료 소식 글도 있음) → 사장님 앱에서 메뉴가 보이면 추가, 없으면 생략 |
| ③ 토스 간편송금(전화번호로 보내기) | — | **전화번호 노출** | 사용 안 함 (공개 사이트에 연락처를 쓸 수 없음 — 사규 개인정보) |
| ④ 계좌번호 직접 게시 | — | 노출 | **금지** (사규) |

무엇을 (개발팀):
1. `public/support.html` 1장 (R-003 페이지와 같은 페이지):
   - 제목 "만든 사람 응원하기", 문구: "게임은 앞으로도 무료예요. 서버비에 보태고 싶다면 커피 한 잔 값이면 충분해요." — 대가(아이템·혜택) 없음, 금액 강요 없음.
   - 버튼 `💛 카카오페이로 응원하기` (+ 토스 링크가 있으면 `💙 토스로 응원하기`). PC에서는 같은 링크의 QR 이미지를 함께 보여 줌(휴대폰으로 찍어서 보내기).
   - 링크는 파일 맨 위 상수 `SUPPORT = { kakao: '', toss: '' }` 에만 둔다. **값이 빈 칸이면 버튼을 숨기고** "준비 중" 문구만. → 사장님이 링크를 주시면 상수 한 줄만 채우면 됨.
   - 안내 한 줄: "송금은 카카오페이·토스 앱 안에서 처리되며, 이 사이트는 결제 정보를 받지 않습니다."
2. 진입 경로는 R-003 그대로: 사이트 푸터 링크 + 엔딩 화면 맨 아래 작은 텍스트 링크 1개. **게임 진행 화면·광고 슬롯 근처 금지.**
3. **토스 미니앱·MS 스토어 앱에는 넣지 않는다**(앱 안 외부 송금 유도는 플랫폼 정책 위험, 토스 틴즈 노출). `cp.js`처럼 aptgame.kr 웹에서만 표시.
4. 측정: 버튼 클릭 시 `stat('support_click', 'kakao'|'toss')` (실제 송금 여부는 알 수 없음 → 사장님 앱 입금 내역으로만 확인).

예상 효과(보수적, 월): 방문 300명 중 0~2명 × 3천~5천원 ≈ **월 0~1만원** (R-003과 같음). 가입 단계가 없어져 '실제로 켜지는 날'이 앞당겨지는 게 핵심.

정책 위험: **광고 정책 위험 없음** (광고 슬롯·광고 문구와 무관, 웹 전용).
- 사장님 판단 필요(링크를 주시는 것으로 동의 갈음): 송금하는 사람 화면에 받는 분 이름이 (일부 가려진 형태로) 보일 수 있음 — 카카오페이 송금 화면 기준. 싫으시면 ②토스 아이디(닉네임 표시)만 쓰거나 R-003 후원 플랫폼으로.
- 세금: 후원금은 소득으로 신고 대상일 수 있음 → 금액이 쌓이면 재무팀이 정리(세무 전문가 확인 권장, 우리는 세무사가 아님).
- 개인 송금 서비스의 영리 사용 조건은 각 사 약관 기준 — 사장님이 약관을 확인·동의하는 영역이라 우리는 판단하지 않음.

사장님이 할 일: `board/사장님할일.md` 의 R-003 후원 줄을 이 방법으로 바꿈 (📄 howto/후원-송금링크.md).

크기: 소(페이지 1장, 링크 없으면 숨김)
