# P-002 '투잡 = 투잡의 기적(e11)' 쏠림 풀기 — 엔딩 조건을 "투잡으로 첫 집을 샀다"로 좁히기
상태: 자동승인 (기획팀 2026-11-25, 크기 소·되돌릴 수 있음 — 사규 '밸런스는 담당 부서 자동승인')
게임: 서울아파트 / 종류: 엔딩 조건 조정
부서: 🎨 기획팀 / 올린 날짜: 2026-11-25

왜:
- QA 밸런스 메모 닷새 연속(11/20~11/24): 투잡 전략은 2015 모드 e11 73~82%, 2026 모드 67~75%. 혼합 전략도 e11 68~78%. "투잡 하면 무조건 투잡의 기적"이라 결과가 뻔하고 다른 엔딩을 가린다.
- 지금 조건 `S.w.two >= 8`(20년 40반기 중 8번)은 투잡 전략이면 10년 안에 저절로 채워짐. 엔딩 이름은 '투잡으로 집을 샀다'인데, 실제로는 집을 산 **뒤** 투잡을 해도 받는다 → 이야기와 조건이 안 맞음.
- e11은 레어(r)라 일반(n) 엔딩을 모두 덮어 버림 → e30·e33 같은 실패 엔딩이 안 나오는 원인 중 하나.

무엇을 (개발팀):
1. `S.st.twoPre`(첫 집 마련 **전**에 투잡을 한 횟수) 카운터 추가: 투잡 반기를 셀 때 `isHomeless()`이고 아직 `S.firstHome`이 없으면 +1. 옛 저장 데이터는 `S.st.twoPre ??= S.w.two`로 시작(기존 판 불이익 없음).
2. `src/seoul/turn.js` endingCands(): `if (S.w.two >= 8) C.push('e11');` → `if (S.st.twoPre >= 6) C.push('e11');`
3. 도감 조건 문구 `src/seoul/endings.js` e11 d: `'투잡을 8번 이상 뛰고 서울 집 마련'` → `'첫 집을 사기 전에 투잡을 6번 이상 뛰어 서울 집 마련'`
4. e12(쓰리잡)도 같은 방식이 자연스럽지만 지금은 0회 도달이라 그대로 둠(더 어려워지면 아예 안 나옴).

기대 효과: 투잡 전략 e11 비율 75% → 40~50% 예상. 빈자리는 e1·e13·e36·e33 등으로 분산.
측정: QA 봇 960판에서 투잡·혼합 전략 e11 비율이 60% 아래로 내려가는지. 30% 아래로 너무 떨어지면 6→5로 완화, 그래도 60% 넘으면 되돌림 없이 7로.

어디를 고치나: src/seoul/turn.js(endingCands, 투잡 카운트하는 곳), src/seoul/endings.js(e11 d 문구), src/seoul/life.js(카운터 초기화)
위험: 이미 도감에 e11을 가진 사람은 그대로 유지(도감 데이터 안 건드림). 밸런스 영향은 엔딩 분포뿐, 돈·확률 변화 없음.
크기: 소(30분)
