# R-005 서울아파트 안드로이드 마켓 입점 (원스토어·갤럭시 스토어 / 구글 플레이)
상태: 대기
부서: 🚀 출시·플랫폼팀 / 올린 날짜: 2026-11-23 / 관련: 사장님 지시 '새로운 플랫폼 런칭하자'(11/21), R-004 후속

왜: 지금은 웹·토스·MS에서만 할 수 있음. 안드로이드 마켓에서 '부동산 게임'을 검색하는 사람에게 노출되면 판수↑ → 광고 노출↑. 앱은 웹을 띄우는 TWA 방식이라 웹 수정이 바로 반영되고 유지비 0.

선택지
- ① **원스토어 + 갤럭시 스토어만** (돈 0원, 추천): 둘 다 가입 무료. 같은 APK 1개로 제출.
- ② ① + **구글 플레이** (등록비 25달러 1회, 사장님 카드): 이용자 가장 많음. 단 개인 계정은 테스터 12명이 14일 연속 테스트해야 정식 출시 가능.
