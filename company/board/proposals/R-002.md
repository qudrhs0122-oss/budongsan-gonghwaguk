# R-002 서울아파트 엔딩 화면: '다른 게임' 교차 홍보를 작은 링크 → 카드로
상태: 자동승인
> ⚠️ **미구현 (11/24 수익화팀 코드 확인)**: 11/21 개발팀 보고엔 "구현완료"로 적혔지만 `src/seoul/ui.js`에 `xpromo` 카드(부루마블 교차 홍보)가 없음. 위 상태 줄의 "(자동승인 → 구현완료)" 안내 문구를 완료 표시로 읽은 것으로 보임 → 개발팀 다음 출근 때 구현 부탁. 끝나면 상태를 `구현완료`로.
게임: 서울아파트(첫 아파트) / 종류: 새 기능(교차 홍보)
부서: 💰 수익화팀 / 올린 날짜: 2026-11-20

왜:
- 엔딩 화면(ui.js 753행) 맨 아래에 `← aptgame.kr 다른 게임` 텍스트 링크만 있음. 눈에 잘 안 띔.
- 한 사람이 게임을 하나 더 하면 판수·배너 노출·보상형 기회가 그대로 늘어남. 부루마블(`/bluemarble`)은 판마다 결과 전면 1회 + 보상형 2회 자리가 있음.

무엇을:
- 엔딩 버튼 묶음(공유·다시 살기·도감) **아래에 한 칸 띄우고** 작은 카드 1장:
  `🎲 다음 판은 친구랑? — 부동산 부루마블` / 부제 `실거래가 단지로 땅따먹기 · 1판 10분` / 누르면 `/bluemarble`로 이동.
- 카드에는 '광고'·'AD' 표시를 하지 않는다(자사 게임 안내라 광고가 아님). 외부 광고 슬롯 옆에 붙이지 않는다.
- 기존 텍스트 링크는 카드로 대체. 토스 미니앱 번들(toss-seoul)에서는 외부 사이트 이동이 안 될 수 있으니 **토스 번들에서는 카드 숨김**(기존 링크 처리 방식 따르기).
- (측정) 카드 클릭 시 `stat('xpromo', 'bluemarble')`.

어디를 고치나: `src/seoul/ui.js` 엔딩 화면 HTML(753행 근처), `src/seoul/shell.html` 카드 스타일 몇 줄.

예상 효과(보수적): 엔딩 도달자의 3~5%가 부루마블로 이동 가정. 지금은 표본이 없어 금액 추정 불가 — R-001 숫자 쌓이면 다음 출근 때 클릭 수로 확인.

정책 위험: 없음 (광고 아님, 광고 배치 변경 없음, 클릭 유도 문구 없음, 버튼과 간격 유지).

크기: 소(1시간)
