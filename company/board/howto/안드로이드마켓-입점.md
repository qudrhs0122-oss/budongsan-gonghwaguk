# 원스토어·갤럭시 스토어 입점 따라 하기 (R-005 승인 후)
준비물은 출시팀이 다 만들어 두었습니다. 사장님은 **가입·본인인증·마지막 제출 버튼**만 하시면 됩니다. 총 30~40분.

## 1. 원스토어 개발자 가입 (무료, 10분)
1. https://dev.onestore.co.kr 접속 → '회원가입' → 개인 개발자 선택
2. 휴대폰 본인인증 → 약관 동의(사장님 직접)
3. 개발자명: `부동산공화국 게임즈` (등급분류 자체등급 정보의 등록자명과 같아야 하니 이 이름으로 통일)
4. 정산 정보(계좌)는 무료 앱이라 지금은 건너뛰어도 됩니다

## 2. 갤럭시 스토어 셀러 포털 가입 (무료, 15분 + 승인 며칠)
1. https://seller.samsungapps.com 접속 → 삼성 계정으로 로그인
2. 셀러 포털 가입 → 약관 동의(사장님 직접)
3. 무료 앱도 '판매자(Commercial seller)' 전환이 필요합니다: 상단 프로필 → 판매자 전환 신청 → 개인 선택, 안내에 따라 정보 입력 (승인까지 며칠)

## 3. Claude에게 넘기기
Claude 대화창(사장님 컴퓨터 연결)에서 아래를 그대로 보내세요:
```
원스토어 입점 진행해. 준비물은 release/ 폴더(STATUS.md 참고). 서명 키는 내 컴퓨터에 만들고 저장소에는 넣지 마.
```
