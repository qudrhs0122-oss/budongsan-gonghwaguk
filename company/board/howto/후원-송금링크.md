# 💛 후원 받기 — 카카오페이 송금 링크 만들기 (약 2분, 가입 없음)

목표: 사이트 '만든 사람 응원하기' 페이지에 넣을 **링크 1개**를 받는 것. 계좌번호는 절대 사이트에 안 들어갑니다.
※ 앱 업데이트에 따라 메뉴 이름·위치가 조금 다를 수 있어요. 막히면 앱 안 검색창에 아래 **굵은 글자**를 그대로 검색하세요.

## A. 카카오페이 (추천)
1. 휴대폰에서 **카카오페이 앱**(또는 카카오톡 → 더보기 → 페이)을 연다.
2. 검색창에 **송금코드** (안 나오면 **QR 송금** 또는 **내 QR**)를 검색해 연다.
3. 내 송금 QR이 보이면 **공유 → 링크 복사**를 누른다. (링크 복사가 없으면 **QR 이미지 저장**도 괜찮아요)
4. 받는 사람 이름이 송금 화면에 어떻게 보이는지 한 번 확인한다(보통 일부 가려져 보임). 괜찮으면 다음으로.
5. Claude 대화창이나 상황판 지시(수익화팀/개발팀)에 아래를 붙여넣는다:

```
후원 링크: (복사한 링크 붙여넣기)
```

## B. 토스 (선택, 메뉴가 있을 때만)
1. 토스 앱 → 검색창에 **토스아이디** 검색.
2. 메뉴가 있으면 아이디(닉네임)를 만들고 **링크 복사**(toss.me/○○ 형태). 메뉴가 없으면 서비스가 끝난 것이니 **건너뛰세요.**
3. 위 5번처럼 `토스 링크: …` 로 알려 주세요.

## ❌ 하지 말 것
- 계좌번호·전화번호를 알려 주거나 사이트에 넣기 (공개 저장소라 그대로 노출됨)
- 토스 '전화번호로 보내기' 방식 (번호가 드러남)

## 끝나면
개발팀이 `support.html` 상수에 링크만 넣고 버튼을 켭니다. 웹(aptgame.kr)에만 보이고 토스·MS 앱에는 안 보입니다.
후원금은 소득 신고 대상일 수 있어요 — 쌓이면 재무팀이 정리해 드립니다.
