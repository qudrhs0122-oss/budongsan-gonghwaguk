# 성수 분양권을 샀는데 '없어졌다'고 나옴 — 잔금 부족 시 예고 없이 계약 해지
상태: 확인완료
심각도: 높음
게임: 서울아파트
출처: 사장님 제보 (11/20)
재현 방법: 청약으로 '(가상) 성수 리버포레'(14.8억) 등 고가 분양권 당첨 → 3년 뒤 입주 연도 짝수 턴에 moveInBun() 실행 → 10·15 규제(유주택자 주담대 불가, 한도 6억 등)로 잔금대출이 부족 → 전매 제한이면 '계약 해지, 계약금 몰수'로 분양권이 사라짐. 사전 경고·선택권 없음.
QA 수치(봇 960판): 분양권 계약 해지 20회, 입주 직전 급매 13회, 입주권 분담금 부족 급매 9회.
기대 결과: 플레이어가 납득할 수 있어야 함.
수정 방향(개발팀):
 1. 입주 1년 전(yearOf() === p.mv - 1) 한 번 '잔금 준비 안내' 이벤트: 예상 잔금·대출 한도·부족액을 숫자로 보여주고 선택지 제공 — ①세입자 받아 잔금 충당(규제상 가능할 때) ②지금 분양권 매도(전매 가능할 때) ③가족 도움/신용대출로 메우기(행복·신용 대가) ④그대로 간다.
 2. 해지·급매 순간은 일반 로그가 아니라 결과 팝업(이벤트 카드)으로 보여주고, 왜 그렇게 됐는지(대출 한도 X억, 부족 Y억) 한 줄 설명.
 3. 청약 당첨 순간에도 "입주 때 잔금 약 X억 필요" 문구 추가.
검증: QA 봇에서 '분양권 잔금 부족 → 계약 해지'가 줄고, 안내 이벤트가 입주 1년 전에 반드시 1번 나오는지 확인.
재발 날짜: 2026-11-21 (미수정 2일째) — 봇 960판: 계약 해지 18회, 입주 직전 급매 10회, 분담금 부족 급매 6회.

## 개발팀 처리 (2026-11-21)
원인: moveInBun()이 입주 턴에 바로 잔금 부족 → 해지/급매를 처리하고, 결과는 '시장 소식' 목록에만 묻혀 있었음. 사전 안내 없음.
수정:
 1. 입주 1년 전(yearOf() >= mv-1) 분양권마다 한 번 '입주 1년 전 — 잔금 준비' 이벤트(events.js BUNPREP, turn.js에서 갈림길 다음 우선순위로 띄움). 필요한 돈·대출 한도(이유)·부족액을 숫자로 보여 주고 선택지 4개: ①세입자 받아 보증금으로 잔금(전세 낀 매수 허용 규제일 때만, 입주 때 내 집은 그대로·세입자 계약) ②지금 분양권 매도(전매 가능할 때) ③가족 도움·신용대출(행복 −8, 신용대출 한도 내) ④그대로 간다.
 2. 해지·급매 때 '필요한 돈 X 중 잔금대출 한도 Y(이유), 내 현금 Z → W 부족' 설명 줄 추가, 반기 결과 화면 다음에 '⚠️ 내 자산 소식' 팝업으로 먼저 보여 줌(입주권 분담금 급매·현금청산도 같이).
 3. 청약·무순위 당첨 문구와 계약금 부족 당첨 팝업에 '입주 때 중도금 상환·잔금 약 X(대출 포함) 필요' 추가.
 4. 같이 고침: 청약 분양권을 세입자 낀 집으로 바꾸면 '세입자 퇴거'·'세놓기'에서 AP[p.aid].jr 읽다 오류 → 가상 단지는 전세가율 0.5로 처리.
검증: 개발팀 별도 봇 400판 — 잔금 안내 이벤트 407회, 같은 분양권 중복 0회, '안내 없이 해지·급매' 0회. QA 게이트 봇은 선택지를 무작위로 고르므로 해지 건수는 판마다 출렁임(오늘 11~25회).
