# '입주 1년 전 — 잔금 준비' 카드: 신용대출 표시 금액과 실제로 빌리는 금액이 다름
상태: 접수
심각도: 낮음 (표시 숫자 불일치, 진행에는 지장 없음)
게임: 서울아파트
출처: 사장님 지시 11/21(선택 뒤 값 확인) 조사 중 코드 점검 (11/22)
재현 방법: 분양권 보유 → 입주 1년 전 '잔금 준비' 카드 → ③ [🤝 가족 도움·신용대출로 메운다]
 - 설명 문구(events.js BUNPREP): `신용대출 최대 ${won(Math.min(room, Math.max(short, .1)))}`
 - 실제 처리(f): `take = Math.min(room, short + .05)`
 예) 부족액 3,000만·신용 여유 1억 → 카드엔 '최대 3,000만원', 실제로는 3,500만원을 빌림
 예) 부족액 200만·여유 1억 → 카드엔 '최대 1,000만원', 실제로는 700만원
 (부족액이 신용 여유보다 크면 둘 다 '여유 전액'이라 일치 — 오늘 실제 화면 검사에서는 4,800만원으로 일치함)
기대 결과: 카드에 적힌 금액 = 실제로 빌리는 금액.
수정 방향: 두 식을 하나로 (예: `const take = r2(Math.min(room, short + .05))`를 run()에서 한 번 계산해 문구와 f에서 같이 사용).
