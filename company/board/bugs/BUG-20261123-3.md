# 2015 모드의 실제 금리 구간(2015~2025년)에 가상 '기준금리 인하' 이벤트가 나와 실제와 다른 금리를 보여 줌
상태: 접수
심각도: 보통 (2015 모드는 실제 역사를 따라가는 모드인데 사실과 다른 숫자가 표시됨. 다음 반기에 실제 금리로 되돌아감)
게임: 서울아파트
출처: QA 오늘의 집중 점검(월: 2015 모드 전 구간) — 실제 화면 2판 + 봇
재현 방법: 2015 모드 아무 판. 예) B판 2017년 하반기 '기준금리 인하 — 기준금리 0.75%. 다음 반기 집값에 훈풍이 붑니다.' → 다음 반기(2018년 상반기) 결과 화면은 '기준금리 1.50%'.
기대 결과: 2015~2025년(HIST 표 구간)에는 실제 기준금리 흐름만 나옴. (실제 2017년은 1.25% → 11월 1.50% 인상)
실제 결과: 가상 인하 이벤트가 2015 모드 1판에 평균 약 1번 나옴(봇 2015 모드 480판 중 463회). 표시 금리가 0.75%처럼 실제보다 낮고, 다음 반기에 '인하' 설명 없이 원래 금리로 튀어 오름. 집값 가산(gShock 1.5)도 실제 역사에 덧붙여짐.
원인: events.js 31줄 `rateDown`의 가중치 `w: () => S.rate > 1 ? 4 : 0`에 역사 구간 제외 조건이 없음. 바로 위 금리 급등 이벤트(20~21줄)는 `S.mode === 'hist' && S.t < HIST.length` 구간을 막아 두었음.
수정 방향(제안): rateDown 가중치에 금리 급등 이벤트와 같은 역사 구간 제외 조건 추가 (한 줄).
QA 검사: `seoul_sim.js`에 경고로 추가. 개발팀이 `수정완료`로 바꾸면 오류로 승격.
