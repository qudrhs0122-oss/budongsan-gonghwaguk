# '지금 매수 가능'인데 [실거주로 매수하고 입주] 버튼을 눌러도 아무 일도 안 일어남 (대출 슬라이더 내림)
상태: 접수
심각도: 높음
게임: 서울아파트
출처: QA 사람 눈 검사 (11/21, 360px 실제 화면 1판)
재현 방법:
 1. 2015 모드, 보통 자금으로 시작 → 2016년 상반기 홈 카드 '지금 바로 첫 집을 살 수 있어요!', 추천 단지 '상계주공 7단지 ✅ 지금 매수 가능'
 2. 단지를 눌러 [실거주로 매수하고 입주] 클릭 → 팝업이 그대로, 안내 문구도 없음 (2턴 연속 같은 증상)
 3. 자동 재현: 현금을 '딱 살 수 있을 만큼'으로 맞추면 매매 단지 24곳 중 20곳에서 매수 실패
원인(추정): ui.js aptModal의 `<input type="range" id="loanR" min="0" max="${q.lim.max}" step="0.05">`. 한도(예: 1.73억)가 0.05 단위가 아니면 브라우저가 값을 1.70억으로 내림 → doBuy(aid,'live',1.70)에서 필요한 현금이 최대 500만 원 늘어 `return false`. 실패 시 토스트·안내도 없음.
기대 결과: 버튼이 켜져 있으면 매수가 돼야 함. (최대 한도 그대로 쓰거나, 실패하면 '현금 X원 부족' 안내)
실제 결과: 아무 반응 없음. 이용자는 버튼이 고장 난 줄 앎.
수정 방향(개발팀): 슬라이더 max/value를 0.05 단위로 올림하지 말고 `step="any"` 또는 버튼 클릭 시 `loanR.value == loanR.max`면 q.lim.max 사용 + doBuy 실패 시 토스트로 부족액 안내.
