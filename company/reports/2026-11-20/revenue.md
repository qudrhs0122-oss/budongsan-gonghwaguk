- 운영팀 `reports/metrics.csv`: **아직 데이터 0줄**(머리글만 있음).
- `/api/stats`(aptgame.kr): 이번 실행 환경에서 **접속 차단**돼 못 봤습니다. → 사장님 확인 필요 없음, 운영팀 metrics.csv가 채워지면 그걸로 봅니다.
- 완주율: **계산 불가** — 서버에 `ending`(엔딩 도달)은 쌓이지만 `start`(판 시작) 이벤트가 없음 → R-001로 해결.
- 판당 광고 노출(코드 기준 추정):
  - 서울아파트: 한 판 40반기(10챕터). 전면광고 표시 시점 8·16·24·32반기 = 최대 4회, 3분 간격 제한이라 실제 2~4회. 보상형 자리: 성과급(챕터마다 1회, 최대 10) + 체력(최대 2) + 힌트 3종(각 1) + 히든 엔딩 힌트(1회). → **판당 전면 2~4 + 보상형 선택 0~16**.
  - 부루마블: 게임 종료 후 전면 1회 + 보상형 판당 최대 2회 + 로비 보상형 + 배너 2자리.

## 🔍 광고 코드 점검 (레드라인 기준)
| 항목 | 결과 |
|---|---|
| 클릭 유도 문구 | 없음 ✅ (보상형 버튼은 "광고 보고 ○○ 받기" — 보상 안내라 문제없음) |
| 버튼 옆·위를 덮는 광고 | 없음 ✅. 서울아파트 반기 결과 화면의 보상형 버튼은 '다음 반기로' 버튼과 카드 4~5개 떨어져 있음 |
| 전면광고 시점 | 서울: 반기·챕터 전환(자연스러운 쉬는 지점), 시작 직후 아님, **3분 간격 코드 확인**(`Date.now() - lastInter < 180000`) ✅ / 부루마블: 게임 끝난 뒤 1회 ✅ |
| 보상형은 이용자가 원할 때만 | ✅ 모두 버튼을 눌러야 시작 |
| 광고 계정 설정·비밀값 | 건드리지 않음 |

참고(위반 아님, 관찰만): 부루마블 게임판 하단 배너(`gbanner`)가 자산 영역 바로 아래 12px 간격. 자산 영역에 누르는 버튼이 많아지면 실수 클릭 위험이 생길 수 있어 다음 점검 때 모바일 화면으로 다시 보겠습니다.
참고: 서울아파트 체력 보상 버튼에 깜빡임(pulse) 효과가 있음. 보상형이라 정책 위반은 아니지만, 이용자 짜증 지표가 생기면 재검토.
