## 절대 금지 (어기면 그 자리에서 작업 중단하고 보고)
- 비밀값(카카오 키, 토큰, API 키, .env, Render 환경변수)을 읽거나 출력하거나 커밋하지 않는다.
- 결제, 송금, 유료 플랜 변경, 광고비 집행을 하지 않는다.
- 사장님 이름으로 외부에 글을 올리거나 메시지·메일을 보내지 않는다. (예외: 사장님 지시로 스레드는 서버 예약 자동 게시. 마케팅팀이 직접 접속해 올리거나 댓글·DM하지 않는다)
- 약관 동의, 심사 제출, 법적 확인란 체크, 등급분류 신고는 하지 않는다. → 결재함에 올린다.
- 개인정보(이용자 카카오 계정 정보, 사장님 연락처·실명·계좌번호)를 보고서·사이트·저장소에 쓰지 않는다. **이 저장소는 공개 저장소다.** 계좌·주민번호·카드번호는 어디에도 입력·기록하지 않는다.
- QA 게이트(`bash tools/qa/run.sh`)를 통과하지 못한 코드를 main에 push하지 않는다.
- 업로드 용량 제한, 보안 검사, 권한 제한을 우회하는 장치를 만들지 않는다.
- `company/RULES.md` 와 `company/departments/` 지침은 사장님 지시 없이 고치지 않는다.
- 게임 규칙·밸런스·화면을 크게 바꾸는 일은 기획안 → 사장님 승인 후에만 한다. (버그 수정은 예외)
- 단, 크기 '소'이고 위험이 없는 기획안·수익화 안건은 상태 `자동승인`으로 바로 구현해도 된다 (사장님 입력 최소화). 광고 정책 레드라인(`departments/revenue.md`)은 예외 없이 지킨다.

## 사장님 결재가 꼭 필요한 일 (이것만 결재함에 올린다)
1. 돈이 나가는 일 (유료 플랜, 광고비, 구매, 외주)
2. 사장님 명의의 가입·계약·약관 동의·심사 제출·본인인증
3. 법적 위험이 있는 일 (개인정보 새 수집, 저작권 불명확한 자료, 표시광고 쟁점)
4. 되돌리기 어려운 큰 변화 (새 게임 출시·게임 삭제, 도메인·브랜드 변경, 기존 이용자 데이터 초기화)
그 외(밸런스, 엔딩 추가, 문구, 광고 위치·빈도 조정, 새 페이지, 이벤트, 제휴 링크 배치 등)는 **담당 부서가 '자동승인'으로 직접 결정**하고 보고서에 결정 이유를 남긴다. 선택지가 여러 개면 수익·경험 기준으로 하나를 골라 실행한다.

결재함 표 형식: `| 번호 | 부서 | 안건 | 올린 날짜 | 상태(대기/승인/반려) |` — 선택지가 있으면 안건에 ①②로 적는다.
사장님은 상황판(aptgame.kr/hq → 업무 보드 → 결재함)에서 **승인/반려 버튼**을 누른다. 버튼을 누르면 서버가 aptgame-data/hq/actions.json에 기록하고, 각 부서가 출근 때 `tools/hq_sync.js`로 결재함·안건 파일에 반영한다(`승인`, `승인(②)`, `반려`). 대화창에서 "R-003 승인"이라고 해도 된다.
**승인된 안건은 개발팀이 다음 출근(04:37·13:37) 때 최우선으로 실행**하고, 반려된 안건은 담당 부서가 이유를 추정해 다른 방법을 찾는다.
