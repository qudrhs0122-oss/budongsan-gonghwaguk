## 출근 절차
1. 저장소 위치: `/home/claude/budongsan-gonghwaguk` (없으면 add_repo로 `qudrhs0122-oss/budongsan-gonghwaguk`를 push 권한으로 붙이고 clone).
   조합장 원본은 `qudrhs0122-oss/johapjang-game` (필요한 부서만).
2. `git pull --rebase` 로 최신화.
3. `company/RULES.md` → 자기 부서 `company/departments/*.md` 순서로 읽고 그대로 일한다.
4. 보고서는 `company/reports/YYYY-MM-DD/<부서>.md` (한국 날짜, `TZ=Asia/Seoul date +%F`). 한국어로, 사장님이 읽기 쉽게.
5. 끝나면 커밋·push. 커밋 메시지는 `[부서명] 요약` 형식. 다른 부서와 충돌하면 `git pull --rebase` 후 다시 push.

## 절대 금지 (어기면 그 자리에서 작업 중단하고 보고)
- 비밀값(카카오 키, 토큰, API 키, .env, Render 환경변수)을 읽거나 출력하거나 커밋하지 않는다.
- 결제, 송금, 유료 플랜 변경, 광고비 집행을 하지 않는다.
- 사장님 이름으로 외부에 글을 올리거나 메시지·메일을 보내지 않는다. (스레드 글은 '게시대기' 초안까지만, 올리기 버튼은 사장님이 누름)
- 약관 동의, 심사 제출, 법적 확인란 체크, 등급분류 신고는 하지 않는다. → 결재함에 올린다.
- 개인정보(이용자 카카오 계정 정보, 사장님 연락처·실명·계좌번호)를 보고서·사이트·저장소에 쓰지 않는다. **이 저장소는 공개 저장소다.** 계좌·주민번호·카드번호는 어디에도 입력·기록하지 않는다.
- QA 게이트(`bash tools/qa/run.sh`)를 통과하지 못한 코드를 main에 push하지 않는다.
- 업로드 용량 제한, 보안 검사, 권한 제한을 우회하는 장치를 만들지 않는다.
- `company/RULES.md` 와 `company/departments/` 지침은 사장님 지시 없이 고치지 않는다.
- 게임 규칙·밸런스·화면을 크게 바꾸는 일은 기획안 → 사장님 승인 후에만 한다. (버그 수정은 예외)
- 단, 크기 '소'이고 위험이 없는 기획안·수익화 안건은 상태 `자동승인`으로 바로 구현해도 된다 (사장님 입력 최소화). 광고 정책 레드라인(`departments/revenue.md`)은 예외 없이 지킨다.

## 사장님이 직접 해야 하는 일
본인인증·계좌·세금·약관·로그인처럼 대신 못 하는 일은 `company/board/사장님할일.md`에 체크박스로 추가한다(중복 금지). 상황판 대표실 카드에 표시된다.

## 결재가 필요한 일
`company/board/결재함.md` 표에 한 줄 추가: `| 번호 | 부서 | 안건 | 올린 날짜 | 상태(대기/승인/반려) |`
사장님이 대화에서 승인/반려라고 하면 그 대화의 Claude가 상태를 바꾼다.
