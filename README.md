# 부동산 공화국 🏙️

대한민국 아파트 부루마블 웹게임 — AI 대전 · 온라인 친구 대전 · 전체 주간 랭킹

## 구조
- `public/` — 게임 화면 (index.html + 이미지)
- `server.js` — 온라인 매칭/중계 + 랭킹 서버 (외부 패키지 없음, Node 18+)
  - 접속 순서대로 4명씩 방 생성 (1번방, 2번방 …), 2명 이상이면 30초 뒤 자동 시작
  - 첫 입장자(방장)가 게임을 진행하고 나머지는 실시간 동기화 (SSE)
  - 연결이 끊긴 플레이어는 AI가 대신 플레이
  - `/api/ranking` 전체 주간 누적 랭킹 (매주 월요일 초기화)

## 로컬 실행
```
node server.js   # http://localhost:3000
```

## 배포 (Render)
main 브랜치에 push 하면 자동으로 다시 배포됩니다.

## 광고 켜기 (Render → 서비스 → Environment)
| 키 | 값 | 설명 |
|---|---|---|
| `ADSENSE_CLIENT` | (기본값 ca-pub-2150655592231599) | AdSense 게시자 ID, `/ads.txt` 자동 생성 |
| `ADSENSE_H5` | `on` | H5 Games Ads 승인 후 켜기 → 보상형·전면 광고가 데모에서 실제 광고로 전환 |
| `ADSENSE_TEST` | `on` | 테스트 광고(가짜)로 동작 확인. 승인 후 삭제 |
| `ADSENSE_BANNER_SLOT` | `1234567890` | 배너 광고 단위 ID (로비·게임판·결과 화면 배너) |

보상형(골드 주사위·재굴림·건설 할인·세금 감면·긴급 지원금·고니 해금)과 게임 종료 전면 광고는 H5 Games Ads(adBreak) 승인이 필요합니다.
광고가 없거나 차단된 경우 "지금은 볼 수 있는 광고가 없어요"로 넘어가고 게임은 계속됩니다.
